# S6E9 scored prediction collection

Updated September 24, 2026 UTC. **Latest best public ROC AUC: 0.94657.**

`submission_latest_best.csv` contains the exact predictions from submission **56510229**, first in our public-score-sorted submission history at this snapshot. It contains 286,571 test rows. No private-score or full-collection OOF claim is made.

## Current ranked collection

- **211 own scored submissions** with the observed Kaggle Public Score sort position.
- **438 verified public notebook outputs**, including scored historical versions and the latest verified files in this collection.
- `ranked_catalog_latest.csv`: file paths, displayed public scores, source URLs, submission/version IDs and SHA256 hashes.
- `ranked_predictions_latest.zip.bin`: all 649 prediction CSVs plus the catalog. This is a standard ZIP stored with a `.bin` suffix to preserve its exact archive structure. Rename to `.zip` after download or open directly with Python zipfile.

`displayed_score_rank` gives equal displayed scores the same rank. `display_order` is presentation order only. `own_sort_position` records actual ordering within our own submission history; it is blank for public notebook files. No extra score decimals are inferred for this release. Distinct scored events and versions are retained even when their predictions match. Ambiguous multi-output versions without a verified submitted file are excluded.

These are prediction scores, not hidden test labels. A few source files contain finite ranking margins outside [0,1], identified in the catalog; their values are preserved rather than clipped. File hashes refer to the original CSV bytes inside the archive.

## Compatibility

The older `ranked_scored_history.zip.bin`, `history_catalog.csv`, optimizer replay assets and `submission_curvature9_lgbpair05.csv` remain unchanged for existing notebook users. They describe earlier snapshots. Use the new `latest` files for the current collection. The compatibility reference is not the current best.
